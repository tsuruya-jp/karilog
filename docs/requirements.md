# Karilog 要件定義書

## 1. プロジェクト概要

### 1.1 サービス名
**Karilog（カリログ）**

### 1.2 サービス概要
射撃および狩猟の帳簿をデジタル管理するWebサービス。
実包管理帳簿、出猟カレンダーなどの機能を提供し、法的な記録義務を果たすとともに、警察提出用のPDF出力に対応する。

### 1.3 ビジョン
「猟師の頼れる相棒」として、煩雑な帳簿管理をシンプルにし、猟師が本来の活動に集中できる環境を提供する。

---

## 2. ターゲットユーザー

### 2.1 主要ユーザー層
- 個人の猟師
- 射撃選手
- 有害鳥獣駆除に従事する専門家

### 2.2 ユーザー規模感
- 趣味で年数回出猟する人
- 頻繁に活動するベテラン猟師
- クレー射撃を楽しむスポーツシューター

## 3. ビジネス要件

### 3.1 ビジネスモデル
| 項目 | 内容 |
|------|------|
| 料金体系 | 無料 |

## 4. 機能要件

### 4.1 コア機能（MVP）

#### 4.1.1 実包管理帳簿（法的要件）
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 購入記録 | 購入日、購入先、弾種、口径、数量を記録 | 高 |
| 使用記録 | 使用日、使用場所、使用数、残数を記録 | 高 |
| 残数管理 | 現在の所持数を自動計算 | 高 |
| 譲受可能残数表示 | 許可上限に対する残数を表示 | 高 |
| 上限警告 | 許可上限を超える購入時に警告 | 高 |
| PDF出力 | 警察提出用フォーマットで出力 | 高 |

#### 4.1.2 出猟カレンダー（スケジュール管理）
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 予定登録 | 出猟予定日を登録 | 中 |
| 実績記録 | 出猟実績を記録 | 中 |
| 場所記録 | 出猟場所を記録 | 中 |
| 実包使用紐付け | 実包使用記録との連携 | 中 |
| 統計表示 | 月別・年別の出猟回数表示 | 中 |

### 4.2 サポート機能

#### 4.2.1 銃砲登録
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 銃種選択 | 散弾銃・ライフルを選択 | 高 |
| 基本情報登録 | 名称、銃番号、許可番号 | 高 |
| 適合実包設定 | 口径等を登録 | 高 |
| 複数銃登録 | 複数の銃を管理可能 | 高 |
| 編集・削除 | 登録内容の変更・削除 | 高 |

#### 4.2.2 ユーザー認証
| 機能 | 説明 | 優先度 |
|------|------|--------|
| ユーザー登録 | メールアドレス＋パスワード | 高 |
| メール確認 | 登録時のメールアドレス確認 | 高 |
| ログイン/ログアウト | JWT認証 | 高 |
| パスワードリセット | メールでリセットリンク送信 | 高 |
| アカウントロック | 5回失敗で30分ロック | 高 |
| アカウント削除 | 論理削除 | 高 |

### 4.3 将来的な拡張（対象外）

- モバイルアプリ
- オフライン機能
- コミュニティ機能
- 狩猟マップ連携
- 射撃スコア管理

## 5. 非機能要件

### 5.1 技術要件
| 項目 | 要件 |
|------|------|
| 現状の管理方法 | 紙またはExcel/Googleスプレッドシートからの移行 |
| 地域性 | 考慮しない（全国統一仕様） |
| オフライン対応 | 必須ではないが、あると良い |
| デバイス間同期 | 必要 |
| データエクスポート | 警察提出用PDF出力が必須 |

### 5.2 セキュリティ要件
| 項目 | 要件 |
|------|------|
| パスワード保存 | Argon2idでハッシュ化 |
| 通信 | HTTPS必須 |
| 認証方式 | JWT（アクセストークン1時間、リフレッシュ30日） |
| アカウント保護 | ログイン失敗5回で30分ロック |
| データ分離 | ユーザーごとに完全分離（マルチテナンシー） |

### 5.3 パフォーマンス要件
| 項目 | 目標値 |
|------|--------|
| API応答時間 | 95%ile 500ms以下 |
| 同時接続数 | 100ユーザー |
| データ保持期間 | 無期限（論理削除） |

### 5.4 可用性要件
| 項目 | 目標値 |
|------|--------|
| 稼働率 | 99%（月間ダウンタイム7.3時間以内） |
| バックアップ | 日次 |

## 7. 用語定義

| 用語 | 定義 |
|------|------|
| 実包 | 銃弾のこと。散弾、ライフル弾など |
| 口径 | 銃身の内径。12番、20番、.308など |
| 弾種 | 実包の種類。散弾のサイズ（7.5号等）やスラッグなど |
| 譲受 | 銃砲店等から実包を購入すること |
| 譲受可能残数 | 許可上限から現在の所持数を引いた、追加購入可能な数 |
| 出猟 | 狩猟に出かけること |
| 猟友会 | 狩猟者の団体 |
| 有害鳥獣駆除 | 農作物被害等を防ぐための駆除活動 |
